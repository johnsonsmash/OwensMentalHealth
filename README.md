- Favicon pack at repo root: `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png`, `android-chrome-192x192.png`, `android-chrome-512x512.png`
- `og-image.jpg` at repo root

## Deploy (no terminal)
1. Go to `github.com/johnsonsmash/OwensMentalHealth` → **Add file → Upload files**.
2. Drag everything from this zip into the **repo root**. If asked, choose **Replace** for existing files.
3. **Commit changes** — Netlify redeploys automatically.

## Edit carousel captions/links
In `index.html`, search for `id="gallery-data"` and edit the JSON list.
